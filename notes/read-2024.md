## 2024-A-2405424 · 七鳃鳗性别比
- **标题**：Lamprey: a Vivid Example of the Doctrine of the Mean（西安交大）
- **模型与算法**：以 Lotka-Volterra 捕食模型与 Nicholson-Bailey 宿主-寄生模型为基底，建三个对照模型：Ideal Reference Model（理想参照）、Constant Sex Ratio Model（恒定性别比）、Models of Changing Sex Ratios（变性别比）；Task 3 用熵权法评生态系统稳定性。
- **检验/灵敏度**：专节 Rationalization Analysis（结果与生态学常识三点对照）+ Sensitivity Testing 两路扰动：人为捕捞冲击、种群初值变化，结论为系统不崩溃、适用不同初值。
- **作图风格**：图极多（31 图），以种群/资源随时间变化曲线和生态系统示意图为主，图注多为短名词短语。
- **Summary 写法亮点**：按 Task 1–4 逐问推进，每问给明确结论句（如变性别比使种群更稳但规模更小），末段打包交代合理性+灵敏度+优缺点。
- **可借招**：三模型对照（参照/恒定/变化）正是我们问题1「弱-only / 弱+强 / 多源」三变体对照表的原型；扰动分两路（外生冲击 + 初值）可对应问题3 失效冲击 + 参数初值两类检验。

## 2024-B-2407038 · 潜水器搜救（UESTC）
- **标题**：Unlocking the Abyss: A Dynamical Model for Deep-Sea Adventure Safety and Rescue Strategies
- **模型与算法**：三模型分工——Model I：ARIMA + 岭回归拟合三维海流与海水密度场，再建牛顿动力学方程预测轨迹；Model II：多目标优化（总成本/可用性/准备时间）+ 遗传算法求 Pareto 集做装备配置；Model III：海域栅格化 + Poisson 概率分布 + Bayes 逐轮更新搜索概率，按时间区间累积发现概率。
- **检验/灵敏度**：随机输入时间序列测不确定性（平均 2.39%）；迁移到加勒比海验可扩展性；时间间隔 ±5%/±10% 灵敏度给出硬数字：参数变化 <10% 时最终概率变化率 <5.8%。
- **作图风格**：23 图 14 表；轨迹图、Pareto 前沿图、预测 vs 实测对照图；Summary 直接点名结果图号（Figure 6 / Table 8 / Figure 10）。
- **Summary 写法亮点**：Model I/II/III 编号与正文一一对应，每段方法+结果+落点图表，末段把可扩展性、灵敏度数字、给希腊政府的备忘录一并收尾。
- **可借招**：栅格+概率分布+Bayes 逐轮更新，是问题2 多源互修正的现成叙事框架（每多收一份源副本=一次后验更新）；灵敏度报「参数变 X% → 结果变 Y%」的配对数字，我们失真参数检验照抄此格式。

## 2024-B-2419984 · 潜水器搜救（同济）
- **标题**：Time is Life: Precise Localization and Faster Search
- **模型与算法**：定位模型用四阶 Runge-Kutta 数值求解动力学方程出轨迹；装备用熵权法 + 成本-效益模型打分（结论：无人机海面搜索 + 声呐水下 + 少量 AUV 深区）；搜索把海域离散成网格，Monte Carlo 得每格出现概率，再用蚁群算法规划路径、目标函数随时间用 Bayesian 概率模型更新——10 小时内发现概率 43%。
- **检验/灵敏度**：§5.3 专节列四类不确定性（初始位置/初速、海流、地形）；§9 对三向阻力系数 ±1%/2%/4% 做灵敏度并报偏差界：10 h 后 xy 偏差 ≤400 m、z 向 ≤40 m，判为可接受。

- **可借招**：Monte Carlo 在网格上出概率分布 + 路径算法消费该分布，与我们问题3「随机失效抽样 → 重连优化」同构；灵敏度给「偏差上界 + 是否影响下游决策」的判语（如「不影响网格级决策」），我们可写「不改变强连接点集合」式判语。

## 本批共性

1. **结构高度统一**：9 篇全部是 Summary → 目录 → 引言（背景/重述/Our Work）→ 假设与符号 → 分问建模 → 灵敏度专节 → 优缺点 → 结论；D 题两篇与 B 题四篇连小节命名都近乎一致。我们的论文照此骨架不会出错。
2. **模型必命名、分问必分段**：每篇都给模型起专名（…Model 结尾），Summary 按 Task/Problem/Model 编号逐问复述且与正文一一对应；数字（概率、误差界、得分）必进 Summary，B 题四篇尤其明显（2.39%、43%、0.4157、87.2% 等）。
3. **灵敏度是标配且必须带数字**：9 篇全部有灵敏度/不确定性专节或专段，做法集中在三类——单参数百分比扰动（±1%~±10%）、情景替换（迁移海域、极端天气、战争、失效式冲击）、初值扰动；且普遍给出「变化界 + 是否影响决策」的判语，而非只说不敏感。
4. **评价类子问题清一色熵权打头**：装备/客户/稳定性评价分别用了 EWM-TOPSIS、EWM+成本效益、EWM 三级指标、EWM+AHP——多指标选型在 O 奖里默认先过熵权。
5. **作图以「流程图开局 + 曲线/分布图扛结果」**：9 篇均在前两图内放工作流程/框架图；结果呈现以轨迹束、概率分布、得分条图为主，图注多为短名词短语、少数带判读句（2429211 的图注判读最规范）。
6. **交付物意识**：B 题三篇附给希腊政府的备忘录、F 题 2409949 附给 WWF 的一页备忘录——Summary 里都会点名交代；我们的问题3 应急预案可同理包装成一个命名的交付物（如应急重连手册/预案表）。
