## 2. 逐类拆解

### 2.1 流程图（全员必备，位置固定：第 3–5 页、公式之前）
四种实看形态：
- **色带分区式（2504188 Fig.2 “Our Work”）**：三个模型各占一条横带，带头色条写模型名（酒红 Model 1 / 绿 Model 2 / 橙 Model 3），带内浅粉/浅绿填充的小框 + 内嵌缩略图（把后面章节的解图缩印进流程框），底部再加一条蓝色“应用”带。信息密度最高，占版心约 55% 页高。
- **四象限式（2507692 Fig.2）**：2×2 虚线边框面板，Model I/II/III + Insight 各一格，格内浅彩填充（米、薄荷、薰衣草、粉），小框 + 细箭头。比色带式留白多、最易读。
- **单色蛇形式（2516219 Fig.3）**：全图只用一种深蓝（圆角框、白字），虚线分面板，红色罗马数字 I–IV 标阶段顺序，弯箭头回环，上行左→右、下行右→左蛇行推进。单色反而最显专业。
- **动词象限式（2425792 Fig.3 “Our Approach”）**：四格以大号动词命名（Locate 蓝 / Prepare 绿 / Search 紫 / Extrapolate 品红），格内深色框白字，菱形框专给 Kalman “Predict–Update” 环，格间嵌小图（热力缩略、Voronoi 图）。与它的 Summary 动词段落一一对应。
- **素框式（2116496 Fig.5、2503268 Fig.1）**：2116496 是灰底黑框竖排五步 + 右侧配一张几何原理图，一图两件（算法流 + 原理）；2503268 三面板各有页眉色带（灰蓝 / 豆沙红 / 鼠尾草绿，低饱和），细线框 + 小字，最接近期刊排版。
共性：框 = 圆角或直角矩形、填充必浅色或深色二选一（深色框必白字）；箭头细、直角或弯弧；阶段必有编号或命名；图内不写长句，每框 ≤8 词。

### 2.2 数据图（正文主体，工具默认风 + 少量定制）
- **坐标与网格**：matplotlib/seaborn 风占多数——2429211 Fig.4 是典型 seaborn 灰底白网格双联线图；MATLAB 风见 2504188 Fig.7（多线时序、图例在图内右上、小字）。坐标轴标签必带量纲/单位，刻度朝内。
- **图例位置**：压倒性在图内（右上居多），不占版心外空间；多线图图例字号明显小于正文。
- **标注方式**：①关键值直接印在图上——2516695 Sobol 条末印 0.42/0.35/0.28，2300229 图内文字块写图例释义，2116496 解图角上嵌数据表；②显著性/阈值用图内大字——2510006 五个置信水平小多图每幅图内印粗体 “60%/80%/90%/95%/99%”；③误差棒是预测类标配——2510006 柱图橙色误差棒表 90% CI，2516695 Fig.23 柱图带 95% CI 与显著性横线。
- **小多图（small multiples）**：同构图成组重复是造“分析感”的主手法——2510006 同一奖牌图 ×5 置信水平、2507692 塌桥前后 3D 图 ×3 组、2300229 三国雷达并排。单幅图普遍偏小（1/3–1/2 版心宽），靠成组撑场面。
- **配色**：数据图以蓝系为绝对主色（深浅蓝双色编码两组，如 2516695 Sobol 深蓝=一阶、浅蓝=交互；2510006 深蓝柱 + 橙误差棒是少见的蓝橙对比）；红只用于第二组/对照组（2510006 上界红线、2504223 KM 曲线蓝橙、森林图蓝红双点）。

### 2.3 网络/地图解图（本题最该学的一类）
- **标红 = 关键集**：2019-D Fig.11 是范式——全图蓝色椭圆节点，绿节点 = 有直达出口者，**红边 = min-cut 瓶颈边**，图内右侧附文字图例块（缩略词表），图注末句给判读指令（见 §4）。2023-D-2300229 Fig.2 同理：红线 = 正相关、蓝线 = 负相关，图例压在每幅子图上方小字。
- **双色语义边**：2304962 Fig.6 圆形布局网络，正文先交代语义再上图——橙红边 = 支持、浅蓝边 = 拮抗，亮度 = 权重；节点环形均布、标签在圈外。
- **前后对照必同版式**：2304962 Fig.13 两张同布局浅绿节点网络左右并置（实施 SDG4 前/后）；2504188 Fig.6 左红粉密网（塌前）→ 中间桥图标 + 红叉 + 黄箭头 → 右稀疏网（塌后），用象形符号讲“发生了什么”；2519935 Fig.11 左右双地图（通勤/非通勤）共用一条蓝→红发散色标居中下方，图内斜体棕字直接标注 “Beltway / Bridge-II”。
- **地图底图三档**：①卫星影像（2116496 解图：深色卫星图上叠黄色虚线覆盖圈 + 编号 + 图标图例竖列右侧，左上角把结果表嵌进图内，数字与预算都在图上）；②浅色政区图（2504223：青绿海面 + 米白陆地，3D 峰形符号表强度；2516695：灰白世界图 + 蓝红气泡，图内含比例尺、指北针、色标条）；③示意网络图（2429211 Fig.3：黑白圆圈 + 箭头，边上只标受控弧 c₃,t₃，图注解释未标弧的含义）。
- **着色规则**：节点/区域着色只承载一个变量（类别或强度），强度一律连续色标 + colorbar，类别一律离散图例；没见一篇在同一图里混两个变量编码到同一通道。

## 3. 配色与版式共性

- **主色倾向**：蓝是全场主色（流程图、数据图、网络图皆然）；第二色是红/橙，只承担“对照、关键、警告”语义；绿多用于“方案/改进后/正向”一侧（2504188 Model 2 绿带、2304962 节点浅绿）。整篇彩虹色乱用者无——即便多色流程图（2425792）也是四格各一色、格内同色深浅。
- **饱和度分两派**：中国队多用中高饱和的 PPT 风填充（2425792、2504188、2516219 的深蓝）；2429211、2503268 走低饱和/素色（黑白网络图、seaborn 灰网格、豆沙色带）——后者在实看中明显更“期刊”、更耐看。
- **版式**：图居中、宽度以版心 60–100% 为主；大图（流程图、解图）必整幅宽，小数据图必成对/成组；图与图注作为一个块不跨页拆分（图注紧贴图下）。图密度约每 1.5 页一张，但分布不均：§1 流程图 1 张打头、模型章每节 1–3 张、灵敏度章成组小图收尾。
- **字体**：图内文字多为无衬线（Arial/Helvetica 系）或 MATLAB 默认；图内字号约为正文 60–80%，标题（如有）多在图内顶部而非图注里（2507692 3D 图、2510006 柱图均把标题印在图内）。

## 4. 图注写法

- **位置与编号**：图注一律在图**下方**、居中或左对齐，“Figure N:” + 名词短语标题（如 “Figure 3: Our Approach”）。例外：2116496 用 “Figure 5␣Flow chart of…”（无冒号、双空格），2300229 前几图无冒号——同一篇内格式统一即可。
- **长度两极**：①短式（多数）：5–12 词，只命名不解释（“Figure 10: sensitivity analysis”），解码交给正文——2503268、2304962 为代表；②长式（少数但最出彩）：图注直接写结论与判读法——1924801 Fig.10 图注给出答案 “Maximum flow = 11 (send 6 on the top path and 5 on the bottom path)”；Fig.11 图注三句：定义绿点、定义红边、末句指令 “Any attempt to improve Louvre evacuation time should begin with these edges.”；2429211 Fig.4 图注逐项解码线型与颜色（“solid orange lines … dotted blue lines”）；2516695 Fig.22 图注解释堆叠含义（“dark = first-order, light = interactive”）。
- **规律**：图越是“解图/关键图”，图注越长且带判读句；流程图与数据图图注越短。子图注处理：并置双图各挂各的图注（2510006 Fig.16/17 同行并列），或共用一注 + (a)(b) 标注（2200084 Fig.3 图注用 (a)(b) 分释蓝/绿箭头语义）。

## 5. 落到我们题目的执行规范（style-guide 10 图逐图）

全篇统一色板先定死（学 2516219 单色纪律 + 2429211 低饱和）：主色深蓝 #1f4e79 系（弱连接、常规元素），**红 #c00000 只给强连接/失效/关键集**，绿给“达标/修复后”，灰作底图与非重点。图注格式统一 “Figure N: 短语”，关键图（图 4、7）用长式带判读句，其余短式。

1. **世界城市点位图（Fig.1）**：照 2516695 Fig.6 与 2504223 Fig.2/3 的浅底世界图——米白陆地、浅灰蓝海面，1028 城画深蓝小点，5 个源城市用红色星标 + 名称标注（学 2519935 在图内直接印地名）；图内放比例尺与指北针（2516695 有此细节）。图注短式。
2. **三问流水线流程图（Fig.2）**：照 2425792 Fig.3 的动词象限结构换成三格（Build / Fuse / Recover），或 2516219 的单色蛇形——推荐单色深蓝版（最耐看）：每格大动词 + 3–4 个 ≤8 词小框，格间嵌一张缩略解图（学 2504188 把解图缩印进流程框）。罗马数字 I/II/III 标问序，与 Summary 段落对应。
3. **强/弱连接失真累积示意（Fig.3）**：照 2116496 的“左流程 + 右原理图”一图两件：左画一条路径上 ε 逐跳累积的阶梯线，右画单跳 ε 随距离曲线（弱，陡升至 12% 封顶）与强（0.01% 水平线）的对照；图内直接标注 δ=11% 与 3% 两条阈值虚线。
4. **问题1 解图（Fig.4，全篇最重要）**：照 1924801 Fig.11 的标红范式 + 2116496 解图的印数字法——世界底图上弱边细灰蓝线、**强边粗红线、强节点红圈放大**，北京红星；图角嵌小表印 headline（总成本、强连接数、最大累计失真）；图注用长式：定义红边红点后末句给判读（“Every strong link sits where the weak-only tree first violates δ — improvement attempts should begin with these red nodes.”式）。
5. **成本–阈值曲线（Fig.5）**：照 2429211 Fig.12 的单参数全区间扫描 + Fig.4 的线型解码图注——横轴 δ 从 3% 到 15%，纵轴总成本，强连接数画第二轴或点标注；在 δ=11% 与 3% 处竖虚线标本題两档。图注逐项解码线型颜色。
6. **问题2 多源分配图（Fig.6）**：照 2304962 Fig.6 的双色语义纪律——城市按主源着色（5 色离散图例，低饱和），融合城市（≥2 源）加白色描边/外圈，源城市星标；图例放图内右下。图注短式 + 一句着色规则说明。
7. **问题3 失效前后对照（Fig.7）**：照 2304962 Fig.13 / 2504188 Fig.6——左右同版式同底图：左为失效前，右为 20 城失效后（失效点打红叉、受影响下游点变橙、重连新边粗绿线），中间可加 2504188 式箭头符号；两图共用图例。图注长式，末句报该抽样的达标率与新增成本。
8. **Monte Carlo 直方图（Fig.8）**：照 2510006 的“不确定性成组呈现”思路做单幅精版——达标城市数（或新增成本）分布直方图，竖虚线标均值与 5% 分位，图内印粗体 headline（如 “≥97% cities within δ in 95% of draws”，学 2510006 图内印大字百分比）。
9. **Morris μ–σ 图 + 局部导数条图（Fig.9）**：直接照 2503268 Fig.10 + Fig.11 版式——左 μ*–σ 散点（点旁标参数名），右水平条形按 |局部导数| 排序、条末印数值（学 2516695 条末印 0.42 的做法）。图注短式，解码放正文（2503268 式）。
10. **三表**：符号表（2429211 式：变量集中一表、正文不再逐个释义）；强连接点名单表做成命名交付物（学 1924801 把关键集命名呈现，表题写明 “the Strong-Link Set” 并给总数）；三变体对照表照 2516695 Table 10 的深蓝表头 + 浅蓝隔行底纹，数值带 ± 或区间。

反面清单（实看确认的坑）：图内文字小于正文 50% 后不可读（2507692 流程图小字已近极限，我们流程图每框 ≤8 词且字号 ≥ 正文 70%）；3D 图只在数据真三维时用（2507692 的 3D 气泡可读性明显低于其平面图，禁止为炫技上 3D）；照片只许出现在背景介绍且 ≤1 张。
