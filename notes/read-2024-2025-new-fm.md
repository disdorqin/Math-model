## 2024 O 奖补卡（A/C 题）

### 2024-A-2400996（Adaptive Sex of Lamprey: gift or curse?）
- 题目一句话：七鳃鳗可随资源改变性别比，问其对自身种群与大生态系统的影响；本篇切入点是把种群按幼体/成体分库迭代，并从生物量、多样性、稳定性三维评估生态效应。
- 方法链：Lotka-Volterra 竞争子模型（幼体/成体分库）→ 生物能量学资源-性别比子模型 + 繁殖成本性别比-繁殖率子模型 → 相关矩阵扩展至寄生等物种 → BDS 评估模型（Shannon-Wiener 多样性指数 + 基于方差的稳定性指标 S）
- 检验/灵敏度：对成体转幼体比率 k 与禀赋增长率 b0 做灵敏度分析，结论模型稳定性良好。
- 可借鉴点：把"性别比"拆成资源→性别比、性别比→繁殖率两段函数关系作桥梁子模型，再把种群模型输出直接喂给三维生态评估模型。

### 2024-A-2407093（Coexist or Extinct? Relationship between Lampreys and Environment）
- 题目一句话：七鳃鳗适应性性别比对种群存续与生态系统是利是弊；本篇切入点是先建带性别分化率与幼体生长期的种群模型，再逐题耦合种间关系模型。
- 方法链：Logistic 增长 + 性别分化率 α 与幼体生长期 τ 构成 BFM 模型（微分/差分两形式）→ Lotka-Volterra 与 Nicholson-Bailey 模型刻画天敌/宿主/寄生关系（Simpson 与 Shannon-Wiener 指数算多样性）→ 改变死亡率 μ 做优劣环境模拟 + 反馈模型与相轨线解释稳定性机制 → 抵抗力/恢复力/综合稳定性量化
- 检验/灵敏度：设独立灵敏度分析节，逐参数改变取值计算模型灵敏度（如宿主种群对 rH 高度敏感、对 K 低敏感）。
- 可借鉴点：用"反证式对比"组织全文——α、τ 分别取常数与随时间变化两种情形并行模拟，差异即性别可变性的效应。

### 2024-A-2424371（Magic Sex Ratio : Exploring the Important Role of Lampreys in the Ecosystem）
- 题目一句话：七鳃鳗按资源改变性别比的利弊与生态角色；本篇切入点是把性别比的诱因与效应都写成函数，嵌入河流-海洋双生境种群微分方程。
- 方法链：最小二乘拟合幼体生长率-食物密度函数 + 性别 logistic 函数定性别分化 → 改进 Logistic 与 Lotka-Volterra 方程组（海洋寄生宿主鱼、河流捕食浮游生物，含洄游子模型）→ 有限体积法（FVM）求 PDE 数值解 → 扰动实验 + Shannon 指数变化构建 3-R 指数模型（Resistance、Resilience、Recovery）评稳定性
- 检验/灵敏度：设独立灵敏度分析节，指出宿主鱼增长率 rH 更敏感等结论。
- 可借鉴点：稳定性不空谈——在特定时刻人为扰动改性别比，用扰动前后 Shannon 指数变化算出可比较的 3-R 量化指标。

### 2024-A-2425397（Population analysis of lampreys: a discrete population dynamics model based on age grouping）
- 题目一句话：七鳃鳗可变性别比、变态、一次性繁殖与洄游等特征对种群与生态系统的利弊；本篇切入点是按七个年龄组建离散种群动力学模型统一回答四问。
- 方法链：七龄组离散种群动力学模型（纳入幼体/成体的饵料、竞争者与人工渔业，性别比随环境变）→ 入侵前后种群对比评生态影响 → 资源突变/产卵者骤减/洄游受阻等情景模拟评各生物学特征利弊 → 以抵抗稳定性、恢复稳定性、可持续性为指标做扰动数值实验（波动度 23.28%/33.19%、恢复 18/28 年）→ 加入寄生种群扩展分析
- 检验/灵敏度：设独立"模型灵敏度分析"节，结论种群规模对繁殖系数非常敏感。
- 可借鉴点：一个离散龄组模型贯穿四问，靠换情景（突变、骤减、加寄生者）而非换模型来答题，结构最省力。

### 2024-C-2401298（"Momentum" Exists In Tennis Game As Residual Effect - A Dual-Temporal Bayesian Network Model）
- 题目一句话：网球比赛中"势头"是否存在、如何量化与预测；本篇切入点是把势头定义为朴素二项模型之外的残差效应，再对残差建模预测。
- 方法链：发球方/接发方重加权 + 滑动窗口与 AUC 构造连续表现指标 → Ljung-Box Q 检验与游程检验验随机性（辅以瞬时胜率）→ 朴素二项模型分离出势头残差 → 双时序贝叶斯网络（生理、感知、自我效能等潜变量）预测残差，并以信息熵减少量算因素重要性 → 迁移到女子比赛验证
- 检验/灵敏度：设灵敏度分析节评估模型鲁棒性，并对预测失败场次做归因分析。
- 可借鉴点："势头=基线模型残差"这一定义把抽象概念变成可计算量，贝叶斯网络的熵减又顺带给出因素重要性排序。

### 2024-C-2401445（Unveiling the Dynamics of Tennis）
- 题目一句话：量化网球比赛走势、证明势头存在并预测势头转折点；本篇切入点是先合成一个动态比赛指数 DPI，再用"无势头模拟"反证势头。
- 方法链：GBDT（网格搜索调参，准确率 82.4%）算表现 PE + 六维个人实力 PS + 发球优势 SA 线性合成 DPI=0.28PE+0.32PS+0.4SA → 高斯分布模拟无势头比赛并与真实比分用 DTW 算相似度反证势头存在 → 随机森林分类预测转折（准确率 77.6%）+ HMM 解释球员对势头的反应 → 跨性别/场地类型比赛检验
- 检验/灵敏度：对关键指标加高斯噪声做灵敏度测试，准确率仅降 8%，鲁棒性好。
- 可借鉴点：证伪式证明——先假设势头不存在并模拟整场比赛，再用 DTW 相似度量化"有势头模型更像真实数据"，比直接下结论更有说服力。

### 2024-C-2401919（Harnessing the Power of Momentum: How to Dominate a Tennis Match?）
- 题目一句话：逐分量化网球势头、检验走势波动是否随机并预测转折点；本篇切入点是建 5 大维度 18 指标的逐分评价体系，用灰色预测抓转折。
- 方法链：PCA-TOPSIS 逐分评价模型（5 维度 18 指标，KMO 与 Bartlett 球形检验验证）得势头分数 → ACF/PACF 图 + Ljung-Box 与 Box-Pierce 白噪声检验（p<0.05 拒绝随机假设）→ GM(1,1) 灰色预测模型预测转折点（平均相对误差 0.0378、关联度 0.9895）并做指标-转折点相关分析 → 迁移至 2023 温网女单决赛验证泛化
- 检验/灵敏度：设独立灵敏度分析节，扰动 PCA-TOPSIS 中影响最大的权重检验模型响应，结论准确性与鲁棒性强。
- 可借鉴点：评价体系先过 KMO/Bartlett 适切性检验再用，且转折点给出阈值化操作定义（相邻时刻分差波动超预设阈值）。

### 2024-C-2403774（Uncovering the Hidden Momentum: A Data-Science Exploration of Tennis Match Dynamics）
- 题目一句话：用数据科学量化网球"运动势能"、证明其影响并预测转折点；本篇切入点是多时间尺度特征工程 + 梯度提升量化 + 时序卷积预测的机器学习流水线。
- 方法链：IQR 异常处理 + Current-Past、多尺度（短/中/长）特征设计 + Spearman 相关剔共线 → XGBoost 势头量化模型（5 折交叉验证，MSE 0.02）→ 随机生成比赛与真实比赛对比各相关性指标证势头作用 → 贝叶斯在线变点检测定位转折点 + 网球比赛分时序卷积网络（TCN）预测转折（Top-1 准确率 75.70%）→ 2023 温网女单域迁移测试（MSE 0.025）
- 检验/灵敏度：设独立灵敏度分析节，探究输入变化对模型的影响。
- 可借鉴点：特征按"当前-过去 × 短/中/长尺度"矩阵化构造，再用 Spearman 相关做双重剔除（与因变量高相关及自相关），是可直接套用的时序特征工程模板。

### 2024-C-2406176（标题未提取到）
- 题目一句话：量化网球实时势头、预测大摆动并给对局策略；本篇切入点是把势头定义为赛前胜率与实时胜率之差，并以盘为单位采样预测。
- 方法链：Elo 评级 + IID 假设反算首分获胜概率 p0 → 实时胜率模型（RTWP，去发球优势）构成 RTMQ 势头量化模型，K-S 检验确认势头显著 → Fourier 级数拟合（FSF）追踪势头趋势 → 按盘采样势头趋势值 + 因子分析提炼技术因子 + 多元线性回归做摆动预测（SP，测试准确率 90.44%）→ K-means 聚类 + 混合策略 Nash 均衡给对不同对手的策略
- 检验/灵敏度：设独立灵敏度分析节，结论外部扰动对摆动预测无影响、鲁棒性强。

### 2024-C-2406324（Command the Flow: Analysis and Prediction of Momentum in Tennis Matches）
- 题目一句话：定义并量化网球势头与摆动、证明其非随机并预测走势；本篇切入点是 EWMA 平滑出势头曲线，再用 LSTM 预测、XGBoost 归因。
- 方法链：EWMA 构建势头评价模型并可视化 → 游程检验 + 情境研究证摆动非随机 → LSTM 预测模型（对比 RNN/GRU 选型）+ PCA 与 K-means 聚类的迁移学习提精度 → XGBoost + SHAP 分析与摆动最相关的因素 → 在 2023 WTA 美网女子数据上检验（误差明显变大并解释原因）
- 检验/灵敏度：设独立灵敏度分析节，分别验证 LSTM 步长与 K-means 聚类数的选择。
- 可借鉴点：预测与归因分工——LSTM 只管预测精度，因素重要性另交 XGBoost+SHAP，避免用一个模型硬答两类问题。

### 2024-C-2409404（Riding the Momentum）
- 题目一句话：量化网球球员势头、检验势头是否造成走势波动并预测比赛趋势；本篇切入点是滑动窗口量化势头、CUSUM 找关键时刻、PCA 降维后 XGBoost 预测。
- 方法链：基于滑动窗口的势头量化模型 MQ-SW（含发球优势与失误影响）+ CUSUM 算法识别关键时刻 → 游程检验（p<0.01）验走势与连胜非随机 + 势头离散化后卡方检验证势头为波动成因 → PCA+XGBoost 趋势预测模型 PMT-PX（最重要因素为当前 Point Victor 与 Break PT）→ 混淆矩阵/ROC（AUC 0.75）评估并迁移至美网女单决赛
- 检验/灵敏度：通过改变滑动窗口尺寸与发球优势附加参数做灵敏度分析，结论鲁棒性高。
- 可借鉴点：关键时刻识别不靠肉眼——结合网球规则与 CUSUM 累积和算法定位，与势头曲线互为印证。

### 2024-C-2409961（Momentum Prediction and Core Feature Extraction Based on GRU with Integrated Gradients）
- 题目一句话：刻画网球瞬时得分率、检验势头作用并预测波动、提取核心影响指标；本篇切入点是用 GRU 拟合势头函数，再用积分梯度把黑箱拆回六个能力维度。
- 方法链：三次样条插值平滑离散数据 → 瞬时得分率（ISR）模型捕捉关键时刻 → 独立性检验验势头与胜利不独立 → GRU 预测势头变化 + 积分梯度（Integrated Gradients）对人工划分的六维度做特征解耦，筛出 12 个重要指标并建六维能力评价体系 → 跨性别/赛制/球类数据做泛化测试与误差分析
- 检验/灵敏度：未见独立灵敏度分析节（以第 7 节泛化测试与误差分析代替，检验跨场景预测能力）。
- 可借鉴点：先人工把指标划成六个语义维度再用积分梯度算维度贡献，黑箱模型直接产出可落地的分维度训练建议。

### 2024-C-2410482（标题未提取到）
- 题目一句话：把网球比赛流拆成胜率与势头两件事，检验势头效应是否显著并预测势头跃升；本篇切入点是偏重可解释的经典统计模型路线（马尔可夫 + 状态空间），而非机器学习黑箱。
- 方法链：Markov 模型以条件概率算获胜概率 + 按单分重要性方差严格定义势头 → 假设检验与 Logistic 回归（势头系数 t 检验 p 远小于 0.05、95% 置信区间不含 0，参数用 MLE 估计）证势头显著 → 状态空间模型 + Kalman 滤波预测势头摆动（优于 ARIMA 对照）→ 迁移至女子网球与女子乒乓球验证（女子网球 MSE 0.051）
- 检验/灵敏度：设独立灵敏度分析节，考察不同样本对状态空间模型的影响，并用交叉验证（MAE、R²）核各模型精度。
- 可借鉴点：答辩友好型选型——明确以"数学可解释性优于机器学习"为由选状态空间+Kalman，并留 ARIMA 作对照基线。

### 2024-C-2418251（Momentum: Powerful Magic for Winning）
- 题目一句话：量化网球单局胜率与势头、证明成功非随机并预测累计势头；本篇切入点是三段接力——RNN 出胜率、PCA+SVM 出势头、ARIMA 做预测。
- 方法链：RNN 分别建发球/接发单局胜率模型并可视化比赛流 → 定义含发球分、破发点、连续得分、非受迫失误、跑动距离五特征的潜在分，PCA 取三主成分输入 SVM 势头模型（MSVM）得单局/累计盘势头 → 势头与胜率相关分析（0.704、0.729）证非随机 → ARIMA 预测累计势头 → 用温网 1502 号比赛验证
- 检验/灵敏度：设独立灵敏度分析节，结论势头计算模型对各输入特征高度敏感（如实报告，未回避）。
- 可借鉴点：用前一模型的输出（单局胜率）与后一模型的输出（势头）做相关分析来回答"是否随机"，把两问的模型产物互相咬合。

### 2024-C-2425454（Changing Tides: Momentum Swings in Tennis）
- 题目一句话：捕捉网球比赛流、检验摆动与势头的关联并预测短期摆动；本篇切入点是"杠杆"概念——一分对胜率的改变幅度即势头原料。
- 方法链：Monte Carlo 算每分胜率（盘/局/场）+ 反事实框架定义 Leverage（赢/输一分引起的胜率变化），势头取 Leverage 的指数移动平均 → 游程检验（90% 置信下 45.11% 比赛比分非随机）+ 列联表独立性检验证摆动与势头相关 → 网格搜索随机森林（GSRF）以 43 指标预测未来 s 分的优势转移三分类（训练集准确率 94%，最重要因素为对手总分）→ 因子分析把前 15 因素降为四类因子 → 改 Monte Carlo 为三盘两胜迁移至 2023 温网女单决赛
- 检验/灵敏度：对短期动机效应参数与 GSRF 的分值量参数做灵敏度分析，结论低敏感、高鲁棒。
- 可借鉴点：势头定义走反事实路线——不看你得了多少分，而看这一分让胜率动了多少（Leverage），天然把关键分权重放大。

## 2024 O 奖补卡（D/E/F 题）

### 2024-D-2417004（Regulating the Water of Tomorrow: A Multi-Layer Optimization Model for the Great Lakes）
- 题目一句话：五大湖水位如何兼顾各利益相关方与生态调控，本篇用多层网络模型逐层细化流量过程再做多目标寻优。
- 方法链：五湖基础网络流量模型 → 加入风/雪/冰塞等气象因素的高级流量模型（聚焦安大略湖与圣劳伦斯河，含规则曲线与出流限制） → 多方收益/成本函数构成的多目标优化模型 → NSGA-II 求解最优水位 → 多元线性回归做水量外推验证（2017 年数据）
- 检验/灵敏度：设独立 Sensitivity Analysis 节，结论为最优水位对降水敏感、对融雪不敏感且鲁棒性强；另用 2017 年数据检验模型稳定性与精度。
- 可借鉴点：先建只含主干流量的基础网络、再叠加气象修正因子的分层建模法，复杂系统可先跑通骨架再加细化层。

### 2024-D-2419588（Optimizing Great Lakes Water Management: An Adaptive Hydrological Network Approach）

- 方法链：DGBIF-OMF 动态灰色–贝叶斯集成框架（综合历史趋势/东道主/项目敏感度等多因子）预测各国奖牌并给区间 → 教练效应系数 + 滑动窗口 + 蒙特卡洛模拟估计名帅效应 → 据效应估计为三国选推荐引援项目
- 检验/灵敏度：第 8 节灵敏度分析设五种情景（基准/高东道主效应/低东道主效应/运动员加权/国家加权）对照，并以小提琴图与雷达图做参数灵敏度分析（东道主效应参数最敏感）；另有不确定性与准确性评估专段。
- 可借鉴点：框架命名与「灰色（小样本）+ 贝叶斯（不确定性）」混搭思路——数据稀疏的子问题可用灰色类小样本方法打底再叠不确定性量化。
- 与同题 O 奖的差别：同题 O 奖主框架多为单一范式（计数回归、贝叶斯分层、树模型集成等），本篇把灰色预测与贝叶斯集成拼成命名框架，且名帅效应不用 DID、改用效应系数 + 滑动窗口 + 蒙特卡洛估计。

### 2025-C-2524123（M 奖；Medal Dynamics and Uncertainty: An Extended Poisson Kalman Filter Approach to Olympic Predictions）
- 题目一句话：同为 2028 奥运奖牌预测题，本篇用扩展泊松卡尔曼滤波状态空间模型绕开 2028 特征缺失问题，并以残差 Bootstrap 给区间。
- 方法链：扩展泊松卡尔曼滤波 Ex-Pois-KF 状态空间模型（状态方程设计处理 2028 特征缺失，残差 Bootstrap 构造预测区间） → 与泊松混合效应模型、LSTM 用滚动时窗交叉验证竞速 → 首奖国家数用跳跃过程模型 → 名帅效应用 DID（样本不足、如实报告不显著）
- 检验/灵敏度：未见独立灵敏度节；检验靠滚动时窗交叉验证竞速、模型不确定性度量专节与假设检验体系（分项数系数 0.207–0.309，p<0.001；东道主效应主要在金牌 p<0.01）。
- 可借鉴点：特征缺失用状态方程绕开——预测期特征拿不到时靠状态传播递推而非删变量或填均值；且如实报告 DID 不显著本身成为可信度加分项。
- 与同题 O 奖的差别：同题 O 奖处理预测期信息多靠历史奖牌序列外推或静态特征回归，本篇以状态空间递推为核心、用状态方程显式处理 2028 特征缺失，并把 Ex-Pois-KF 与泊松混合效应、LSTM 做滚动时窗竞速。
