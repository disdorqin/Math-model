### 2020-D（足球传球网络：网络构建→指标→评价/策略）
- **2002526 (O)**：SNA 传球网络（全网加权邻近矩阵/质心/色散、局部核心-边缘与二元/三元模体、个体度中心性）→ 指标筛选+多元线性回归绩效模型。检验：回归整体显著性（95%）+Root MSE=1.5。可借：网络三层（全/局/个体）指标体系可搬到城市网络的枢纽分析。
- **2003723 (O)**：有向加权复杂网络 → AHP+熵权组合的球员评分（13 个子指标）→ 多分类 Logistic 回归辨阵型与胜负机制。检验：共线性处理+回归检验。可借：主客观组合赋权写评价指标的标准链。
- **2006782 (O)**：传球网络+K-means 归类二元/三元构型 → 对抗回归（Adversarial Regression）评价团队协作（遍历权重取最小误差）。可借：用“双方得分须与赛果一致”作约束反推权重——类似我方用守恒约束反推融合参数。
- **2013140 (O)**：多层（宏/中/微）网络分析 → 熵权法合成 6 个归因因子 → 相关显著性检验（p=0.024）；独立灵敏度节（§3.3）。可借：归因因子→合成指标→显著性验证的评价闭环。
- **2013245 (O)**：有向传球网络 → 层次聚类（平均连接）+PCA 提取 6 类合作结构 → 900 秒滑动窗口模型追踪绩效指标动态。检验偏弱：以模式对照为主、无独立灵敏度节（O 奖中少见，卡内如实记）。可借：滑动窗口把静态网络变动态——对应累计失真随路径演化的呈现。
- **2015044 (O)**：无权/加权传球网络+l-pass 短期网络 → 马尔可夫链长期模型 → 三维绩效指标（χ² 检验有效性）+灵敏度分析证鲁棒。可借：短长期双尺度网络（即时拓扑+转移概率）对应单路径与多源两种接收。
- **2022868 (O)**：传球网络风格分析（二/三人构型、对手反制依赖、博弈味建模）→ 独立 Sensitivity + Error Analysis 两节。可借：检验章节的组织方式（灵敏度与误差分开写）。

### 2021-D（音乐影响网络：有向网络→影响力量化→相似度→演化）
- **2100112 (O)**：有向影响网络+三种中心性组合（度/加权度/特征向量）→ PCA 降维+距离相似度+Mann-Whitney 检验（62.8%，p<0.001）→ 流派分类树。可借：多中心性组合成单一影响力指数的做法。
- **2100242 (O)**：改进 PageRank 影响力评价（全网+分流派子网）→ 向量距离相似度 → 影响-相似混合模型。可借：PageRank 变体给“源节点重要性”排序——多源修正时选修正源的现成件。
- **2101855 (O)**：重标定 PageRank（消除时间偏好）→ 加权余弦距离（SGD 以网络结构标签优化权重，MSE）+滞后效应 → 综合测度。可借：用结构标签反训距离权重，接口设计精巧。
- **2105298 (F)**：同代/跨代有向影响网络（权重阈值筛子网）→ PCA（7 主成分>80% 方差）+欧氏距离聚类 → 干预分析模型（Intervention Analysis）量化流派演化对创新速率的影响（Fishing-Out 效应）。检验：用原始变量重聚类对照，结论不变=鲁棒。可借：干预分析对应“某城失效/某目标达成”的前后对照设计。
- **2106028 (O)**：SNA 有向网络影响测度 → 因子分析潜空间相似度 → 离群检测辨流派 → Bollinger Bands 策略识别“革命信号”。可借：把金融技术指标搬来做突变检测，跨界件。
- **2107091 (O)**：时间/流派跨度加权的有向影响网络 → 度中心性+PageRank 改进特征向量中心性（MI 服从幂律、无标度）→ 余弦/欧氏多维相似度模型。可借：先验分布形态（幂律）再谈枢纽。
- **2121604 (O)**：有向影响者网络+冷却模型（影响随时间间隔衰减）→ PCA 四因子+余弦相似度 → 引力模型等统计件补强。可借：影响衰减函数——与失真随距离衰减同构。
- **2124497 (O)**：三指标边权（年代跟随/流派跟随/出度）的加权有向图 → 改进随机分布嵌入（RDE）降维+Bayes 错误率检验分布差异 → Kruskal-Wallis 逐特征剔除 p 值分析。可借：逐件剔除式检验（消融）写“哪个特征真重要”。
- **2124668 (O)**：时间/直接性修正的 Katz 中心性 → 神经网络预测流派（阴性结果照写）→ k-means 自创“声学流派”（模块度 Q=0.17）→ 质心位移检测革命。可借：阴性结果不藏着——Summary 里明说预测失败并转方案。

### 2021-B（野火无人机/应急资源部署：覆盖与选址优化）
- **2102199 (O)**：栅格化 → 多目标优化定 EOC 选址+无人机悬停/侦察路线 → 泊松过程仿真验证 → 禁忌搜索悬停模型。可借：优化+随机过程仿真验证的双保险，正对问题 3。
- **2104673 (O)**：区域离散化+三层（无人机层/信息层/火焰层）建模 → SSA 搜索模式与 EOC/中继选址优化（通信约束）→ 元胞自动机火势仿真+温度-火险拟合做气候适应。可借：分层建模把“资源层/信息层/灾害层”分开——对应强/弱连接双层网。
- **2105363 (O)**：区域安全评价分级 → 容量与成本双目标的数量优化（贪心最大配比求中继机数；结论 200 架 SSA+32 架中继）→ 极端火情预测与前锋队部署调整。可借：Summary 每问落数字的写法（机队配比直接给数）。

- **2127300 (O)**：网格+相关系数火情评价 → 无线电传播损耗模型定中继覆盖 → 遗传算法定机队规模（24 中继+30 SSA，总预算 54 万澳元）→ LSTM 温度预测+回归做十年适应+选址模型。可借：传播损耗→覆盖半径的物理链，对应失真→可达半径。
