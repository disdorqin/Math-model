## 1. 拆题思路：大问题怎么拆成子问题链

O 奖的通用链条是五环：**重述时先把赛题改写成自己的子问题序列 → 假设把每个子问题的前提钉死 → 每个子问题配一个（组）子模型 → 子模型之间用显式接口串成流水线 → 检验环单独成节、且与子模型一一对应**。下面六条是原文核对过的真实链。

### 例 1 · 2021-B-2116496（野火无人机）——流水线型拆题，全批最清晰
- 提出问题：§1.2 Restatement 后 §1.3 Our Work 先给全链；正文 Model I 直接按 Step 编号展开（目录 §4.4–4.7）。
- 假设：§4.1 Local Assumptions 放在 Model I 内部、紧贴第一步之前（不是全文统一假设节）——假设跟着用它的子模型走。
- 子模型链：Step I GMM 预测火线人员部署 → Step II k-means 定 EOC 设施点 → Step III 每簇 Kruskal MST 建中继通道 + 沿边覆盖方程算中继数 → Step IV 两种 SSA 巡航策略；§4.8 另设 Effectiveness Function（AHP 权重）把四步结果合成一个效能分。
- 组合接口：上一步的输出量就是下一步的输入量（部署人数 → 设施点位 → 通道图 → 中继计数），效能函数只做最后的综合评判，不参与求解。
- 检验：Model II 把链条在 2030 气候情景下重跑并对三类极端事件重新计价（EOC +46.15%、SSA +98.08%、中继 +53.75%）；灵敏度只测火场规模与容忍时间两个可动量。
- Summary 与 Step I–IV 编号 1:1 对应，评委读 Summary 即知全文骨架。

### 例 2 · 2019-D-1924801（卢浮宫疏散）——局部标定 → 全局抽象 → 对偶定位 → 适应性
- 提出问题：Summary 首句即点明最高优先级——原文 "Bottleneck identification was our highest priority"（Summary 段），拆题围绕“先定位瓶颈、再谈方案”。
- 子模型链：局部 agent-based 模型测各分区实测疏散速率 → 速率成为全局容量图的边容量 → 最大流求疏散时间（t_min=p/m，24.34 min）→ max-flow/min-cut 对偶定位瓶颈边 → 残余网络给应急人员路径。
- 组合接口：**实测速率 → 边容量** 是两个模型之间唯一的、被明说的接口；min-cut 边集是优化模型与“改进建议”之间的接口（标红上图）。
- 检验环即链条的一环：Adaptation 一节就是删边/加边实验（Richelieu 通道关闭：17.8→11.0 人/s、时间 +64%），失效测试不是事后补的灵敏度，而是模型设计时就预留的操作。
- 结果章节用结论式标题组织（§"The Pyramid is NOT a Bottleneck"、"Ground D is a Bottleneck"），拆题的每一环在结果里都有一个“发现”与之对应。

### 例 3 · 2022-B-2200084（水资源分配）——同一变量系上的三模型接力
- 子模型链：Model 1 资源分配网络（双源串联 × 五州 × 两商品，逐边损耗率 α_ij + 守恒方程，时变 LP，附伪代码）→ Model 2 边际效用（给同一批流量定价、表达州间利益）→ Model 3 IPV 拍卖（稀缺到 LP 不可行时切换的分配规则）。
- 组合接口：三个模型共用同一套流量变量与 α_ij 损耗定义，前一模型的输出（分配量）是后一模型的输入（估值对象、拍卖对象）；切换点由“是否稀缺/可行”这一可判定的条件触发——这是 regime switch 的接口设计范本。
- 检验：§7 Sensitivity 被改写成“更复杂情形”三节（需求增减、可再生占比、节水细则），即用情景替换代替参数扰动；三个自有模型同题对打比较（Model 3 自称优于 Model 1 并给出比较）。
- 反面细节：其 §2 Assumptions 是裸列表（见 §3 例 F），链条再好也被卡片与本遍共同记为该篇最弱处。

### 例 4 · 2023-D-2304962（SDG 网络）——子模型编号即赛题问号
- 子模型链（目录原文）：Sub-model I 建四层关系网络（边=Pearson 相关阵）→ Sub-model II 基于网络的优先级评价（带反馈与时间效应）→ Sub-model III 某目标实现 = 编辑网络后重排 → Sub-model IV 危机 = 扰动矩阵 D_x 作用于 G→G′、配抗干扰指数 c → §7 推广模型 → §8 Robustness Testing 独立成节（与 Pros/Cons 分开）。
- 组合接口：四个子模型共用同一个网络对象 G；III 与 IV 是对 G 的两种编辑算子（实现=单向编辑、危机=扰动矩阵），后面的每个问题都不重建模型、只换算子——拆题的经济性全在这里。
- Summary 用 "For problem one…five" 严格平行，每问方法 + 带数字的命名发现，末句鲁棒性收尾。

### 例 5 · 2024-B-2425792（潜水器搜救）——按任务动词拆题
- 子模型链（目录原文）：Task 1 定位（CFD 简化 Fossen 方程 + Kalman 预测-更新）→ Task 2 装备（PCA 14 指标打分）→ Task 3 搜索（Kalman 协方差 + 多元正态得 95% 置信搜索域、发现概率 CDF）→ Task 4 外推（换加勒比海重跑 = 迁移验证；Voronoi 多艇协作）。
- 组合接口：Task 1 的输出不是点而是**概率分布**，Task 3 直接消费该分布的协方差——“上游输出分布、下游消费分布”是处理累计不确定性的标准接口（对我们：上游输出每城失真分布，下游消费分布做融合/检验）。
- 检验：§7 Sensitivity and Error Analysis 合节，逐参数报 RMSE 并排名；Task 4 的迁移本身就是一类检验（换海域结论是否还成立）。
- 代价同样写在目录里：§3.5 专设 Fine-tuning Kalman Filter——复杂模型要为调参单独付一节的篇幅（见 §2）。

### 例 6 · 2025-D-2504188（巴尔的摩交通网）——先量化冲击、再优化、后应用
- 子模型链（目录原文）：§5 Bridge Collapse Impact Quantification（建网可视化 → 冲击指标量化 → 可达性定义与求解）→ §6 公交网络优化（中心性筛站 + 覆盖最大化非线性规划 + Monte Carlo 评估覆盖，61.37%→78.13%）→ §7 道路可用性优化（Connectivity/Congestion/Mixing 指数 + ADP 路径优化）→ §8 Model Application for Security → §9 Sensitivity → §10 Evaluation。
- 拆题特点：第一问不急于优化，先把“失效造成多大伤害”量化成指标，后两问的优化目标直接引用这些指标——**评价指标先行、优化在后**，是稳健性题目的标准拆法。
- 同题对照：2025-D-2516219 走得更重——网络框架（§5）→ 桥梁影响（§6）→ 多模式网络（§7）→ 干预优化（§8），且在 §8.3 System Disruption Analysis 里把中断写成时变边容量公式组（第 39–41 式，含随机车道关闭参数 κ∼U[0.3,0.6]）；链更长、公式更密，但其灵敏度只落在 §7.6 一处，链长与检验厚度不成比例（见 §2 代价条）。

### 例 7（补）· 2025-C-2514362——每问一模型、每模型一检验
- 子模型链（目录原文）：§4.1 混合效应负二项（奖牌计数主模型）→ §4.2 ZINB（首奖零膨胀）→ §4.3–4.4 项目关系与选择 → §5 贝叶斯修正熵（教练效应）；§4.5 Sensitivity 内含排名波动、模型对比、参数灵敏度、**Ablation Study（§4.5.4）**四件套，§5.5 再配一处灵敏度。
- 拆题特点：模型按数据特征分工（计数→负二项、零多→ZINB、异质→混合效应），每个模型自带 "Model selection background" 小节先讲为什么选它——拆题的理由写在每个子模型门口。
- 同构印证：2025-C-2510862 第 9 章 Model Testing 与模型逐个对应（Stacking 做 CV、PSM-DID 做平衡+灵敏度），“检验与子模型一一对应”是 C 题强篇的共同结构。

## 2. 方法组合学

### 2.1 简单方法组合出复杂效果：接口怎么设计
共同点：单个方法都是教科书级的（k-means、Kruskal、回归、中心性、TOPSIS、Monte Carlo），复杂性来自**串联顺序与接口**，不来自单个模型的深度。接口设计有四种可复制的形态：

| 接口形态 | 做法 | 出处 |
|---|---|---|
| 量→位→图→数（流水线量传递） | 预测量决定设施位、设施位决定图、图边长决定设备数 | 2116496（GMM→k-means→MST→覆盖方程 Σl_j≥距离） |
| 实测→参数（标定接口） | 局部模型/数据的实测值直接成为全局模型的参数 | 1924801（agent 实测速率→边容量）；2429211（时滞互相关+回归标定 LP 参数） |
| 共用变量系（多模型接力） | 后续模型不重建变量，只在同一套变量上换目标/换规则 | 2200084（α_ij、v_ij 贯穿 LP→效用→拍卖）；2304962（同一 G、四种算子） |
| 分布传递（不确定性接口） | 上游输出分布而非点值，下游消费分布 | 2425792（Kalman 协方差→搜索域 CDF）；2407038（栅格概率分布→Bayes 逐轮更新→累积发现概率） |

组合时还有一个反复出现的克制：**评价器不进求解器**。2116496 的 AHP 效能函数只做事后综合评判；2020-D-2002526、2022868 先全量提出候选指标、再用对结果变量的回归筛掉不显著者，筛选器同样站在求解之外。先筛后排、先算后评，求解链保持干净。

### 2.2 上来就复杂模型：效果与代价
- **2425792（CFD 六自由度 + Kalman）**：效果是累计误差有了原理级的压制机制，外推（Task 4）可信；代价是 §3.5 Fine-tuning 专节 + §7 误差分析专节——复杂模型至少多付两节的“自证”篇幅，且 Summary 必须带 RMSE 数字才立得住。
- **2516695（贝叶斯 HAR+MCMC、SBN-DBN、DID-GAN、GNN、LSTM 品牌矩阵）**：效果是每问都有“高级感”命名模型；代价是每个子模型都要自带诊断（其检验靠 Sobol + 情景表硬撑），任何一环诊断缺位都会被看出来。
- **2514362（混合效应负二项 + ZINB + 贝叶斯熵）**：复杂但可辩护的范例——每个复杂模型都对应一个被点名的数据特征（计数、零膨胀、国家异质性），且 §4.1.1/4.2.1 先写 Model selection background。复杂模型的入场券是“特征对位 + 选择理由”。
- **2228168（两阶段规划 + 精英保留 GA + 差分进化精修）**：元启发式路线的典型形态——复杂在求解器不在模型，代价是结果不可复现性要靠情景灵敏度表（干旱 −25%/−50%/−75%）来补。
- **反面对照 2303967**：模型链本身不弱（系统动力学建网 + 熵权 + ARIMA + 动态删/加节点），但 §8 灵敏度只测 ARIMA 的参数 p——复杂模型 + 薄检验是全批最明显的失衡样本；2516219 的公式密度（§8.3 三式连发处理中断）与检验厚度之比同样偏高。结论：**复杂模型的真实成本不在建模，在检验**；检验预算不足时，复杂模型反而扣分。

## 3. 假设写法：论证式假设的句式结构

论证式假设在原文中收敛为五种句式（外加一个反面样本）。共同结构：**假设句（短、断言式）→ 理由从句（because / based on / in other words）→ 后果或缓和句（therefore / this assumption is essential / we choose …）**。

**句式 A：假设 + 独立 Justification 子项**（2425792、2504188）
- 2425792 用 "Assumption N:" + "- Justification:" 两行式。假设句：> "The submersible is a spherical rigid body."（7 词）理由句：> "The choice of spherical shape is based on the principle of isotropy"（13 词），随后接“从而可消去 roll/pitch/yaw”的后果句。
- 2504188 用 ▲Assumption / ▼Justification 图标对，理由先承认困难再给规律性：> "the exact departure and destination points for each stakeholder in the traffic network are difficult to predict"（17 词），再接 "tend to follow certain regularities" 式的可建模性论证。

**句式 B：假设 + In other words 复述 + Because 证据 + 必要性声明**（2022868，全批标杆）
- 其 §3 标题即 "Assumptions & Rationales"。第二条假设的理由核心句：> "Whether a shot goes in generally depends on the individual ability of both the shooter and the goalkeeper"（18 词）——用这条理由把“用射门数不用进球数”的口径钉死，并回溯到全部指标的定义。
- 第一条假设收尾的必要性声明：> "we claim this is a reasonable and practical assumption to make"（11 词），紧接一句 "This assumption is essential to our model" 式表态——假设不是免责声明，而是承重声明。

**句式 C：假设 = 数据口径决策 + 历史/经验理由 + 操作后果**（2514362）
- 其 Assumption 1 整段只做一件事：论证为何只用 1952 年后数据。理由句：> "Olympic Games before 1940 had only a small number of countries to participate."（13 词）后果句直接给出取舍（只用 1952 年后数据建模）并配图佐证（参赛国数对比图）。假设节同时完成了数据清洗的辩护。

**句式 D：假设 + 承认代价 + Therefore 缓和设计**（2304962）
- 其 §2.1 开篇先声明立场：> "we make the following basic assumptions, each of which is properly justified."（13 词）
- 线性假设的缓和句：承认非线性普遍存在、难以估计，随后 > "we choose variables with a sufficiently large correlation coefficient, meaning that we greatly reduce the possible influence"（17 词）——假设的漏洞用建模动作（只选高相关变量）当场补上。

**句式 E：局部假设（Local Assumptions）贴身放置**（2116496）
- 假设不进全文假设节，而是放在 Model I 的 §4.1、紧贴用它的方程之前，且每条假设自带物理后果：> "as long as any repeater receives electromagnetic waves, it can amplify and propagate the signal"（15 词）——后果句直接授权下一步的覆盖方程。适合“只对某个子模型成立”的前提。

**反面样本 F：裸列表**（2200084）
- 其 §2 六条假设全是断言、无一条理由，其中最承重的一条是：> "The loss of water and electricity during transport is proportional to the transporting distance."（15 词）——α_ij 的全部合法性压在这一句上却不给论证。tier1 深读与第一遍卡片均将其记为该篇最弱处。教训：越是承重的假设越要论证，裸列表省下的篇幅会在可信度上加倍偿还。

## 4. 写作风格：可执行清单

### 4.1 章节衔接
- [ ] 引言四件套固定顺序：Background → Restatement → Our Work/Our Approach（含框架图）→（2429211 式）方法概览小节；框架图在前 4 页内出现（2429211、2304962、2116496 均然）。
- [ ] 子模型之间设“桥段”：2303967 专设 §3.4 "Section Summary: from Indicator Network to Goal Network"——用一小节明说上游产物如何变成下游输入；没有桥段时，至少在下游小节首段用一句 "Based on the … obtained in Section X" 回指（2504188 §6 首段式）。
- [ ] 模型与检验之间设“解释层”：2429211 在两层 LP 之后单设第 4 章 Model Insights，再进灵敏度——先解释机制、再做检验，评委不会在数字里迷路。
- [ ] 检验节位置跟随拆题方式：链式拆题用统一检验节（2425792 §7）；分问分模型用逐模型检验（2514362 §4.5 + §5.5、2510862 第 9 章逐个对应）。二选一，全文一致。

### 4.2 结果段落组织
- [ ] 结果小节用结论式标题，不用方法式标题（1924801："The Pyramid is NOT a Bottleneck"；2300229 式跨区一致发现同理）。标题里可以有 NOT、有数字、有地名。
- [ ] 每段结构：方法一句 → 结果一句 → **段末落数字**（2419984：关键数字 43%/10h 落在 Problem 3 段末；2413565：每段 Firstly/Secondly…且数字密度全程在线）。
- [ ] 反直觉结果优先呈现并给机制解释（1924801 金字塔非瓶颈、其入口楼梯才是；2022868 自创指标 null 结果照实报并解释）。
- [ ] 自有变体同表对打（2200084 三模型比较；2405424 三变体对照表），变体数字绝不跨节串用（调研报告已列为禁区）。

### 4.3 Summary 的段落节奏
- [ ] 节奏模板：背景句（1–2 句）→ 逐问段（每问 2–4 句：动词领起 + 方法 + headline 数字）→ 检验/鲁棒一句 → 诚实局限一句 → Keywords。
- [ ] 动词领段（2425792："First, to locate. Then, to prepare. Next, to search. Furthermore, to extrapolate."）或编号领段（2116496 Step I–IV、2304962 For problem one…five），与正文编号严格 1:1。
- [ ] 每问段落的数字配额：至少一个 headline（总成本/概率/误差界/得分），误差类数字带口径（RMSE、95% CI、PICP 择一写明，2514362、2513314 式）。
- [ ] 灵敏度可以进 Summary 且应当进（2516695 单设 "Sensitivity Analysis:" 段、报 GDP 弹性 0.18；2413565 末段报 "初值 ±5% → 变化 ≤0.047%" 式鲁棒界）。
- [ ] 被否方案/失败过程可进 Summary（2107870 声明否决 Reaction-Diffusion；2514461 写 LSTM 失败转 XGBoost）——一句即可，换全篇可信度。
- [ ] 交付物在 Summary 点名（2429211 的 Memo、2318300 的委员会报告、2116496 的计数与预算直接印在解图上）。

## 5. 落到我们题目：1028 城三问的拆题链设计

总判断先行：**走“简单方法组合”路线，复杂性预算花在失真核算、融合规则与鲁棒实验三处，不花在单个模型上**。理由见 5.4。

### 5.1 问题 1（单源北京、单路径、累计失真 ≤11%、成本最小）
链条（每步标方法与接口）：
1. **几何层**：Haversine 距离 + 源城市代表行钉定（北京 OID16/UID41 等，口径用句式 C 写成假设：城市群数据以都会区代表行计）。接口：距离矩阵 + 候选邻居图（按失真上限反推弱边可用长度：单边 ε(d, outdeg) 单调，先解出弱边长度上限再剪枝候选边——剪枝规则本身写成引理）。
2. **核算层**：先给累计失真严格定义（存活率连乘 ∏(1−ε_e)，最终失真 =1−∏），再谈优化（学 2305794“新指标先给核算口径”与 2200084 的 α_ij 守恒式）。
3. **下界层（对照模型）**：MST 总成本下界 + 弱连接-only 可行性普查（多少城弱路径必然超 11%），与主解同表对照（模式 1：打底+对照，2405424）。
4. **主求解层**：先按地理聚类（模式 4，2116496/2522820），逐簇跑失真预算标签剪枝的生成树状图（节点状态=(成本, 累计失真)，删被支配标签）；**强连接只在弱标签集不可行处插入**，插入点即待交付的强连接点集（1924801 的关键集逻辑）。
5. **精修层**：换父局部搜索精修（模式 8，2228168 的“启发式+精修”结构，但精修用确定性局部搜索不用 GA，保可复现）。
6. **交付层**：强连接点命名表 + 解图（强边标红、图上印总成本与强点数，1924801/2116496 式）。
接口清单：距离矩阵（1→2）、存活率定义（2→4 的约束）、簇划分（4 内部）、不可行点集（4→6 的交付物）。检验：δ 全区间扫描（11% 向下，2429211 单参数扫描式）、坐标加噪重跑报强点集稳定性（2300348）、灵敏度只测可动参数（失真三参数 + 强弱成本倍率，2318300 原则）。

### 5.2 问题 2（五源、多源修正、阈值 3%）
链条：
1. **融合规则先行**：像 GGDP 一样先给“最终失真”的核算定义（多份独立副本互修正的合成式），并用 Kalman/Bayes 更新叙事给原理背书（2425792/2407038），规则写死后再优化——顺序不可颠倒（2305794 教训）。
2. **亲和与分配层**：先给每城对五源的亲和指数（距离/失真余量合成），再做分配（模式：2013772 的“指数 + 双目标规划”两段式）；主源分配直接复用问题 1 的逐源树状图求解器（接口复用 = 组合经济性，2304962 的算子复用逻辑）。
3. **修正源增补层**：对单源不达标的城，按“单位成本的失真下降”贪心加第二/第三源（主源 + 修正源搭配，学 2413565 的“主选 + 互补伙伴”最大匹配叙事）；强连接只留给结构性情形——用 2524070 的区分：**结构不可达（任何弱路径组合都超限）必须强连接，参数性超限靠加源/调路径解决**，两类分开列表。
4. **逐城验算层**：1028 城逐城最终失真表（附录）+ 分布图，正文只报最坏城与分位数。
5. **消融层**：去融合、去强连接各重跑一遍，成本/失真差即机制必要性的证据（2514362 的 Ablation Study）。
接口清单：问题 1 求解器（2 复用）、融合核算式（1→3 的达标判据）、不可达分类（3→交付表）。

### 5.3 问题 3（随机 20 城失效、保 3%、成本尽量小）
链条：
1. **失效算子层**：失效 = 对问题 2 网络的节点删除算子（2304962 扰动矩阵语言 + 2303967 删节点重排机制），算子定义一次，随机与定向两种抽法共用。
2. **随机层**：固定种子、20 城分属不同国家、≥100 抽 Monte Carlo；报告口径学 2521556——报“仍达标城市数的分布”与“成本增幅分布”，不报单抽结果。
3. **最坏层**：中心性（介数 + PageRank 改进，2107091/2300229）排序的定向失效 20 城，与随机层并排成两档（随机 ≠ 最坏，两档都要，2504188 的中心性预筛逻辑）。
4. **应急规则层**：每城预置备用父节点/备用源（重连优先级队列，2300229 的重排流程），失效后按队列局部重连、不全局重优化；另报 Maintenance-Time 式指标——重连前仍达标的城市比例（2202748）。
5. **交付层**：应急预案做成命名交付物（预案表：失效情形 → 受影响城 → 备用连接 → 增补成本），学 2429211 备忘录的交付意识。
接口清单：问题 2 的最终网络（1 的作用对象）、达标判据（沿用 5.2 的核算式，全程一个口径）。

### 5.4 为什么走简单组合、不走复杂模型
1. **数据决定上限**：附件只有经纬度与行政区，没有可供复杂模型消化的协变量；复杂模型（如贝叶斯网络、深度模型）在此数据上只能拟合自己造的特征，2514362 式“特征对位”的入场券我们拿不到。
2. **约束是题目给死的显式公式**：失真公式、成本倍率均为题面给定，不需要学习或估计——需要的是在约束下组合出可行且便宜的网络，这正是流水线组合（聚类 + 受约束树 + 贪心增补 + 局部精修）的适用域（2116496 已在同构问题上验证）。
3. **规模与可复现**：n=1028，标签剪枝 + 局部搜索是多项式、可复现、可给下界夹逼的；元启发式/复杂模型在同等篇幅下要额外付调参与自证成本（2425792 的 Fine-tuning 节、2516695 的逐模型诊断），且有 2303967 式“模型重、检验薄”的失衡风险。
4. **评委语法**：2019–2023 批共性第 3 条——网络题的获奖语法已收敛为“建图 → 指标 → 筛选/排序 → 策略”，创新应放在失真约束与融合规则上。我们的新意恰好可全部装进组合接口里：失真预算标签（约束接口）、融合核算式（规则接口）、失效算子（复用接口）——**复杂性放在接口，不放在模型**，与大道至简的 O 奖主流一致。
5. **例外条款**：若问题 2 的贪心增补在 3% 下不可行城过多，允许局部升级一处复杂性——把修正源选择写成小型整数规划精确求解该子问题（子问题规模小、精确可证），其余链条不动。复杂性只许点状使用，且必须自带对照（与贪心结果同表比较）。
