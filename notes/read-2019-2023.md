## 本批共性

1. **结构定式高度一致**：目录、命名模型、灵敏度/检验节、Strengths & Weaknesses 节几乎篇篇齐备；Summary 按问题逐问写、每问必带 headline 数字、关键词行近乎标配。本批 20 篇无一例外有优缺点节。
2. **模型品牌化是普遍动作**：MPMV/PMC/SPMV、DIGNP、Temporal Champagne Tower、GSRF、Adversarial Regression、Maintenance Time Algorithm — 给核心模型起名字并让 Summary 与正文共用同一套名字，是本批最可复制的习惯。
3. **网络题打法收敛**：凡网络题（2019-D、2020-D 三篇、2021-D、2023-D 三篇）都是“建图 → 中心性/motif 指标 → 筛选或排序 → 策略”，区别只在筛选工具（回归、TOPSIS、PageRank、min-cut）。对本题意味着：图 + 指标 + 筛选的链条是评委熟悉的语法，创新点应放在失真约束与融合规则上，而不是图本身。
4. **分配题打法收敛**：2020-F 与 2022-B 三篇均为“守恒/运输模型打底 + 多目标权衡 + 按稀缺程度切换机制（regime switch）”，且都配一个真实案例/国家组做应用验证。本题问题2 可直接沿用此骨架。
5. **检验方式分三流派**：①统计检验流（回归显著性、VIF、交叉验证、人工对照）；②情景扰动流（COVID 参数、指标扰动、干旱/需求情景表、Monte Carlo 分布）；③迁移验证流（换国家/换球队/换案例重跑）。强篇往往叠加两类（如 2300229 扰动 + 灵敏度遍历；2107870 交叉验证 + 否决模型声明）；只做一类且只给定性结论的（2303967 只测 ARIMA 的 p、2305794“趋势合理”式表述）明显偏弱 — 本题检验节应至少做到“扰动 Monte Carlo + 带数字的灵敏度”双保险。
6. **灵敏度只测可动参数**渐成共识：2318300 只测 8/26 个可动参数、2300661 只测初始参数子集、2228168 用情景百分比表 — 与本题“只围绕强连接布点、融合源数等可动量做灵敏度”的计划一致。
7. **作图定式**：框架/流程图（多叫 “Our Work”）几乎篇篇出现在前 4 页；空间/网络题必有地图或网络图且解图上常印关键数字；图注分两派 — 指令型（1924801“改进应从红边开始”）与直陈型（多数），指令型更出彩。本题作图清单（风格文档 §3）与本批证据吻合。
8. **诚实是加分项而非风险**：2107870 在 Summary 否决模型、2022868 报告 null 结果、1924801 在 Summary 自陈弱点 — 本批最受推崇的三篇都把诚实写进 Summary 本身，而非只藏在优缺点节。
