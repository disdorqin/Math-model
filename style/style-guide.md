## 核心结论速览（保留自历遍总结，细节以专册为准）

### Summary 模板要点
> [背景句：什么系统、什么矛盾。] For Problem 1, we [动词] … by [命名模型/算法], obtaining [headline：总成本、强连接数、最大失真]。For Problem 2, we … [融合规则一从句], achieving [headline] under the 3% threshold。For Problem 3, we … [扰动协议], and show [鲁棒数字：如 100 次随机 20 城失效中 ≥X% 城市仍达标、成本增 ≤Y%]。[一句诚实局限。] Keywords: …
- 篇幅 450–550 词；逐问组织，每问「方法群 + 数字收口」；鲁棒句必须给数；关键词 4 个。逐槽位模板与自检清单见 summary-guide 第 7 节。

### 本题色板（定死）
- 深蓝 #1f4e79 = 弱连接/主结构；**红 #c00000 只给强连接/失效/关键集**，不作装饰；绿 = 达标/修复；灰 = 底图。
- 同族图严格同版式同配色；流程图可作唯一「海报页」适度多色，但不引进第五色。详见 figures-guide。

### 红线（本题应用备忘与忌单）
- 问题1：失真预算树状图 + 强边只在弱连接不可行处插入 + 聚类加速；MST 下界与阈值扫描把启发式解夹在界内。
- 问题2：逐边损耗守恒（2200084 的 α_ij 模板）+ 融合规则显式写死 + 逐城验 3%；融合规则先行、顺序不可颠倒。
- 问题3：扰动矩阵 Monte Carlo（≥100 抽）+ 中心性排序的最坏情形；**随机 ≠ 最坏，两者都要报；单抽鲁棒结论是明确禁区**。
- 路线总判：**简单方法组合，复杂性放接口不放模型**；唯一点状例外 = 问题2 修正源选择可上小型整数规划，须与贪心同表对照。
- 忌：裸假设列表、无基准的网络指标、无数字的灵敏度、只有方法的 Summary、装饰图、不同变体数字串用、把评分函数塞进求解器（评价器不进求解器）。
