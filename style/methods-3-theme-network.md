## 2. 方法卡精华（按子主题分组）

### 2.1 网络构建 → 指标 → 评价/策略（2020-D 传球网络组）
- **2002526 (O)**：SNA 传球网络（全网加权邻近矩阵/质心/色散、局部核心-边缘与模体、个体度中心性）→ 指标筛选 + 多元线性回归绩效模型。检验：回归显著性 + Root MSE=1.5。可借：网络三层（全/局/个体）指标体系可搬到城市网络的枢纽分析。
- **2003723 (O)**：有向加权复杂网络 → AHP+熵权组合的球员评分（13 个子指标）→ 多分类 Logistic 回归辨阵型与胜负机制。可借：主客观组合赋权写评价指标的标准链。
- **2006782 (O)**：传球网络 + K-means 归类构型 → 对抗回归评价团队协作（遍历权重取最小误差）。可借：用「双方得分须与赛果一致」作约束反推权重——类似用守恒约束反推融合参数。
- **2013140 (O)**：多层（宏/中/微）网络分析 → 熵权法合成 6 个归因因子 → 相关显著性检验（p=0.024）；独立灵敏度节。可借：归因因子→合成指标→显著性验证的评价闭环。
- **2013245 (O)**：有向传球网络 → 层次聚类 + PCA 提取 6 类合作结构 → 900 秒滑动窗口追踪绩效动态。检验偏弱（无独立灵敏度节，O 奖中少见，卡内如实记）。可借：滑动窗口把静态网络变动态——对应累计失真随路径演化的呈现。
- **2015044 (O)**：无权/加权传球网络 + l-pass 短期网络 → 马尔可夫链长期模型 → 三维绩效指标（χ² 检验）+ 灵敏度分析。可借：短长期双尺度网络（即时拓扑 + 转移概率）对应单路径与多源两种接收。
- **2022868 (O)**：传球网络风格分析（二/三人构型、对手反制依赖）→ 独立 Sensitivity + Error Analysis 两节。可借：检验章节的组织方式（灵敏度与误差分开写）。

### 2.2 影响力量化 → 相似度 → 演化（2021-D 音乐影响网络组）
- **2100112 (O)**：有向影响网络 + 三种中心性组合 → PCA 降维 + 距离相似度 + Mann-Whitney 检验（62.8%，p<0.001）→ 流派分类树。可借：多中心性组合成单一影响力指数。
- **2100242 (O)**：改进 PageRank 影响力评价（全网 + 分流派子网）→ 向量距离相似度 → 影响-相似混合模型。可借：PageRank 变体给「源节点重要性」排序——多源修正时选修正源的现成件。
- **2101855 (O)**：重标定 PageRank（消除时间偏好）→ 加权余弦距离（以网络结构标签优化权重）+ 滞后效应。可借：用结构标签反训距离权重。
- **2105298 (F，西交)**：同代/跨代有向影响网络 → PCA + 欧氏距离聚类 → 干预分析模型量化流派演化影响。检验：用原始变量重聚类对照，结论不变 = 鲁棒。可借：干预分析对应「某城失效/某目标达成」的前后对照设计。
- **2106028 (O)**：SNA 影响测度 → 因子分析潜空间相似度 → 离群检测辨流派 → Bollinger Bands 识别「革命信号」。可借：跨界件做突变检测。
- **2107091 (O)**：时间/流派跨度加权的有向影响网络 → 度中心性 + PageRank 改进特征向量中心性（MI 服从幂律）→ 多维相似度模型。可借：先验分布形态（幂律）再谈枢纽。
- **2121604 (O)**：有向影响者网络 + 冷却模型（影响随时间间隔衰减）→ PCA 四因子 + 余弦相似度 → 引力模型补强。可借：影响衰减函数——与失真随距离衰减同构。
- **2124497 (O)**：三指标边权的加权有向图 → 改进随机分布嵌入降维 + Bayes 错误率检验 → Kruskal-Wallis 逐特征剔除 p 值分析。可借：逐件剔除式检验写「哪个特征真重要」。
- **2124668 (O)**：时间/直接性修正的 Katz 中心性 → 神经网络预测流派（阴性结果照写）→ k-means 自创「声学流派」→ 质心位移检测革命。可借：阴性结果不藏——Summary 里明说预测失败并转方案。

### 2.3 覆盖与选址优化（2021-B 野火部署组）
- **2102199 (O)**：栅格化 → 多目标优化定 EOC 选址 + 无人机路线 → 泊松过程仿真验证 → 禁忌搜索悬停模型。可借：优化 + 随机过程仿真验证的双保险，正对问题 3。
- **2104673 (O)**：区域离散化 + 三层（无人机层/信息层/火焰层）建模 → SSA 搜索模式与 EOC/中继选址优化（通信约束）→ 元胞自动机火势仿真做气候适应。可借：分层建模把资源层/信息层/灾害层分开——对应强/弱连接双层网。
- **2105363 (O)**：区域安全评价分级 → 容量与成本双目标数量优化（贪心最大配比求中继机数）→ 极端火情预测与部署调整。可借：Summary 每问落数字的写法。
- **2116496 (O)**：GMM 火险聚类 → k-means → Kruskal MST 中继网 → 覆盖方程定无人机数。可借：MST 做骨干网 + 覆盖定规模，是问题 1 的现成骨架（拆题链见 methods-1 例 1）。
- **2127300 (O)**：网格 + 相关系数火情评价 → 无线电传播损耗模型定中继覆盖 → 遗传算法定机队规模 → LSTM 温度预测 + 回归做十年适应。可借：传播损耗→覆盖半径的物理链，对应失真→可达半径。

## 3. 各 read 卡中的对题可借招（网络/分配类，节选）

以下出自各年 read-*.md 方法卡的「可借鉴/可借招」行，按用途归类；卡面未逐条标篇号的以源文件为据回查，本册不补造篇号。

**分配与供源规则**
- 熵权-TOPSIS 给需求方定优先序、再按资源水位分阶段切换分配准则——可映射五源情形下按可用量分档切换供源规则（2022-B 水资源组卡）。
- 自创单一「缺水指数 SI」并按指数降序逐个分配的贪心规则——对应应急时按「失真缺口指数」排序逐城重连。
- 双源用耦合差分方程跟踪库存动态，并给出「模型每 100 天重跑一次」的周期更新口径——可借给多源网络做余量滚动重算。
- 先把大区域网格化做 0-1/分配型双目标规划定「谁服务谁」，再用图上最短路（Dijkstra）度量路径代价——两段式可直接迁移到 1028 城单源分配 + 单路径失真核算（2023-B 卡）。
- 给强势参与方设「份额上限」作为公平约束再求均衡——对应枢纽城可能垄断流量时设单源供给份额上限，比较有无上限的成本与均衡度代价。

**网络结构与关键节点**
- 把要素间关系建成网络、用 PageRank 找关键节点——1028 城网络定位关键中转城/脆弱节点可直接借。
- 逐段灵敏度定位「关键路段」再反解容许区间——可迁移为逐边扰动、定位对失真约束最敏感的关键连接。
- 用栅格加卷积核把「相邻单元的外溢影响」叠加到单点指数上——可迁移到刻画相邻节点间的失真传播。
- 路径分析拆解「新资源注入 → 经哪几条通道 → 影响全局指标」——可照此拆解一个源失效后冲击的传导通道（成本上升、失真上升、孤城），抓主通道优先处置。

**多源修正与融合**
- 栅格 + 概率分布 + Bayes 逐轮更新，是问题 2 多源互修正的现成叙事框架（每多收一份源副本 = 一次后验更新）；灵敏度报「参数变 X% → 结果变 Y%」的配对数字格式可照抄（read-2024 卡）。
- Kalman 递归修正 = 累计失真/多源互修正的原理背书；失真报分布/区间不报单点（read-2024 卡）。
- 三维画像 + 最大匹配的「主选 + 互补伙伴」结构，可类比问题 2 每城「主源 + 修正源」的搭配选择（read-2024 卡）。
- EWM-TOPSIS 多指标选型可用于「哪些城市配强连接」的辅助论证（距离、度数、区域重要性多指标）（read-2024 卡）。

**失效与应急（问题 3）**
- 蒙特卡洛生成数据 + PCA 降维评估 + 网络仿真优化的三段链且删节点做灵敏度——与 Q3 随机删 20 城失效的仿真评估框架同构。
- 随机扰动生成大量对照策略、报告自家策略胜过其中 93% 的分位式最优性证据——应急重连方案可用随机失效样本的分位对比证明优于随机重连。
- 为极端情形单设一套覆盖常规规则的优先逻辑——Q3 可把应急重连写成覆盖常规供应规则的独立优先层。
- 「上帝视角」全知最优解作理论上界、再报告自家方案达到上界的比例——Q1 可先算无失真约束的成本下界，给最小成本方案一个可量化的差距标尺。
- 用「失效概率」而非弹性系数给每个外部因素贴敏感/不敏感标签并排处置优先级——可借给随机失效应急做因素筛选与排序。
- 「短期变差、长期变好，并算出恢复到初始水平所需步数」的时间轨迹叙事——Q3 可报告成本/失真随修复步数恢复到失效前水平的轨迹，而非只报终点值。
- 把随机扰动（高斯噪声 + 随机干旱情景）直接写进模型再做系综模拟——Q3 可把失效写成随机变量、多次抽样报告成本/失真的分布。

**分层与骨架**
- 带容量/时延的流网络 + 分层（宏观/微观）优化（2429211，read-2024 卡与 pass2 互证）：问题 1 可分「骨架强连接层（宏观）/ 弱连接接入层（微观）」两层叙事；单参数全区间扫描图可用于 δ 阈值扫描。
- 先用解析必要条件缩小结构、再用数值算法求解的两段式写法——适合给带累计失真约束的最小成本问题先立结构再上数值算法。
- 把管理对象分区、每区用状态变量滚动更新再做整体优化——可类比按城分组、用状态变量滚动更新每城的供应来源与累计失真再做全局优化。

## 5. 深读扩展轮一新增（公式级，来源：deep-reads.md #25–36）

以下为慢读到公式/证明层后对 §2 卡片的增补与修正，数字均可溯回原文页（见各深读条目）：

- **2315167 (F)**：扰动算子有显式公式——目标置零后其余目标按 X*′_{ij} = X*_{ij} − x_{kj}·ρ_{ik} 连带下调（式 10）；但 Task 4 的事件冲击段并未把冲击量代回网络重算，是「有数据点的散文」。另：其 Summary 的 10.32% 与正文 10.78% 不一致（§5.5 为 8.84%→10.78%）。
- **2500387 (M)**：改进 K-shell 的确切形式是 s_i = α·d_i^(w) + (1−α)·n_i（加权度 + 净客流节点权，归一后相加），边权由 BPR 函数 t = t_0[1+α(V/C)^β]（α=0.15、β=4 惯例值）给；断桥前后对照只有方向、无数值增量——卡片「断桥前后对照」应理解为定性对照。
- **2510374 (H)**：随机删 20% 站点 ×100 次的 MC 实验在 §6，报最好/最坏平均距离（无均值/分位）；其灵敏度节数据来源误植北京市交通委数据（巴尔的摩题），引用此篇方法时只借 MC 协议外形。
- **2102199 (O)**：验证 Model II 的机制是「泊松定极端事件期望（十年 2.99431 次）→ 在极端情景下重跑 Model I 优化器 → 报增量成本」，另有 5% 扰动下最大时间误差 3.2657%（§8）。
- **2104673 (O)**：元胞自动机的角色是「函数发生器」——仿真拟合出温度→火险概率→过火面积两级函数再喂部署优化；最终配置 10 SSA + 2 中继；地形影响小于火区面积是其近阴性结论。

## 理解与判断

（本节为汇编者综合判断，非源文件结论；数据部分以各节为准。）

- **主题库对我们真正的价值是「同构件」而不是「同题型」。** 28 篇里没有一篇的题目和我们一样，但至少五件是结构同构的直接移植：MST 骨干 + 覆盖定规模（2116496）、节点置零扰动（2315167）、级联失效（2504020）、K-shell 按业务量改度（2500387）、MPC 滚动修正（2425559）。选件时应按「机制是否同构」排序，而不是按年份或奖级——H 奖的 2425559 同构度高于多篇 O 奖，就是证明。
- **要清醒：主题库的方法卡是「一遍速读」深度。** 这些卡来自第一遍方法卡与主题批速览，每篇只读了方法链与检验节，没有 pass2 那种回原文逐节核对。把某篇的某个数字（满意度 80.82→94.78 之类）写进我们论文的论证之前，必须回原文复核；卡面只够做选型线索，不够做引用依据。
- **网络题的真实配方与直觉有出入。** 对照 methods-2 的 D 题配方（GRAPH 67% + EVAL 52% + MC 33%），主题库里反复出现的是「建网 → 中心性/指标 → 评价排序」这条评价味很重的链，纯优化反而是少数。我们的问题本质是优化题（带约束的最小成本），在 D 题语境里是少数派路线——这既是差异化机会，也意味着评价层不能省：解出最优网络之后，仍需一层网络结构分析与方案评价来「说 D 题的语言」。
- **可借招清单要防「招招都借」。** 第 3 节的招数来自几十张卡的汇编，密度很高，但每招的出处深度不一（有的来自整篇深读，有的只是一张卡的一行）。正确用法是按问题逐问挑 1–2 招并回原文学透，而不是把清单当菜单全点一遍——全点就成了方法堆砌，正好撞上 methods-2 的件数预算（全篇去重 5–7 件）。
- **失效应急是主题库里最成熟的一块。** 节点移除、级联失效、攻击模拟、随机对照分位四种写法都有现成样本，且互相可组合（随机抽样给分布、定向攻击给最坏、级联给连锁）。问题 3 不需要发明检验语言，把这四件按「随机 ≠ 最坏、连锁单列」的口径组好即可——这也是全册里我认为可以直接照搬、不用再创新的部分。
- **一个样本偏差提醒**：主题库的 F/M/H 来自 GitHub 逐队猎取，天然偏向愿意开源的中国队伍；O 奖部分来自官方档案，无此偏差。凡涉及「F/M 常见做法」的判断（如攻击模拟代替灵敏度节），样本量只有个位数，只当线索，不当规律。
- **（扩展轮一新增）问题 3 的检验配置已经凑齐，不必再发明**：结构扰动重算（2315167 置零算子 / 2102199 情景重跑升格为独立模型）+ 随机失效分布（2510374 删站 MC，须升级为报分位 + 接重连优化）+ 级联放大（2504020 负载再分配）+ 定向攻击最坏对照，四件在深读里都核到了公式与协议层。
- **（扩展轮一新增）Q1 的最强同构是「律 → 包络 → 优化」**（2127300：损耗律推出 18.5 km 半径后才进 GA）。失真律先行推出弱连接可行包络、强连接只补包络外与瓶颈，比直接抛带约束优化更符合 O 奖的讲法。
- **（扩展轮一新增）数字口径是主题区最普遍的死法**：2315167 摘要与正文差 0.46 个百分点、2008495 报最好不报平均、2500387 前后对照无数字。定稿须设「摘要数字对账表」（数字、正文页、口径三列），此条优先级高于再多读几篇。
- **（扩展轮一新增）灵敏度的正确打法是打自己的软肋**：2429211 点名 ω 并全区间扫描、2006782 只打平局阈值——我们的灵敏度节应点名融合权重与阈值口径这两个自设量，而不是泛扰动参数。
