## 本题速查

- 弱连接：接收点成本 5，通道 1/1000km；失真 ε^W = min[0.12, 0.007·(d/1000)^1.2·(1+0.5·outdeg(i)/8)]（依赖发送方出度）
- 强连接：成本为弱的 10000 倍（接收点 50,000；通道 10,000/1000km），失真约 0.01%
- 问题 1：单源北京、单路径、累计失真 ≤11%，成本最小，**须列全部强连接点 + 总成本**
- 问题 2：五源（北京/巴黎/莫斯科/伦敦/纽约）多源接收修正，阈值 3%，成本最小
- 问题 3：问题 2 基础上随机失效 20 个不同国家城市，应急重构仍保 3%、成本尽量小
- 源城市数据行：北京 OID16/UID41；巴黎 OID373/UID803；莫斯科 OID614/UID1300；伦敦 OID734/UID1567；纽约待钉（候选 OID915/UID1920）
